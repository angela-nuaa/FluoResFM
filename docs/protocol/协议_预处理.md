# 协议：BioSR-MT 预处理（原始 MRC → bundled example）

> 依据：预处理实验-01（测试 135 图 + 训练 360 图 + 15 SIM + 147,960 patch，逐像素 0 误差 / 2.4e-7 容差内验证）。
> 适用范围：BioSR-MT bundled example 的原始 MRC → 全图/训练 patch 变换。

## 1. 全图变换（已验证，0 误差）

```
RawSIMData_level_0n.mrc
→ 沿第 3 轴 9 帧算术均值（float32）
→ 不裁剪、不归一化、不旋转、不翻转、不转置
→ WF_noise_level_n/<图像编号>.tif
```

```
SIM_gt.mrc 第 0 平面
→ SIM/<图像编号>.tif
```

- MRC 读取用 `read_mrc.py`（BioTISR 补充材料；`order='F'` 重塑）。
- 输出存储形状：WF/参考 `(1,502,502)` float32；SIM `(1,1004,1004)`（2 倍，评估时 `avg_pool2d(k=2)` 降采样对齐）。

## 2. patch 变换（已验证，float32 容差 2.4e-7）

先将 WF 或 SIM 图像截断为非负，各自按每图 P3/P99.5 归一化，再按固定、行优先滑窗切块：

| LR 网格 | 对应 HR 网格 | 索引条目 |
| --- | --- | ---: |
| 32×32，步长 32 | 64×64，步长 64 | 6,750 |
| 64×64，步长 64 | 128×128，步长 128 | 1,470 |

- 归一化：`clip(x, 0, None)` → `(x − P3) / (P99.5 − P3)`（每图全局百分位）。
- patch 存储：`(1,{p},{p})` float32；不 clip 到 [0,1]（可超 1）。
- `train.txt` 只消费样本 1–30；31–40 存在于训练全图目录但不在 bundled patch 索引中。

## 3. 已知无法解决的边界（作者官方代码/文档缺失，但已逐像素验证）

1. **9 帧均值 → float32**：官方 `read_mrc.py` 只有 MRC 读取，无「9 帧均值」步骤；规则由审计反推并 0 误差验证。
2. **训练 patch 网格/步长**（32×32→64×64、64×64→128×128，步长=尺寸非重叠）：论文确认 64×64 与 P3/P99.5，但网格代码未随仓库发布；审计以 2.4e-7 验证。
3. **去噪任务 GT**：example 无干净 WF 参考，论文未定义去噪「高质量」目标；不影响已冻结的去卷积生产链。

> 这些边界是「精确验证过、但缺作者独立文档」级别，非「无证据」。

## 4. 使用流程

1. 读 MRC（`read_mrc.py`，`order='F'`）。
2. 全图：9 帧均值 → 写 TIFF（float32，不处理）；SIM_gt 第 0 平面 → SIM。
3. patch：非负截断 → 每图 P3/P99.5 → 固定滑窗（按上表网格）。
4. 验证：与 bundled example 逐像素比对（全图 0 误差；patch 容差 `1e-6` 内）。

入口：`scripts/materialize_biosr_mt_verified_assets.py`（生产）、`scripts/audit_biosr_mt_raw_equivalence_all_levels.py` / `scripts/audit_biosr_mt_train_patch_equivalence.py`（审计）。
