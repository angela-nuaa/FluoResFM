# 阶段3-02｜生产流程有效性验证

> 状态：已完成（2026-08-07）。前置：阶段 3 探针结论见 `阶段3-01`；本实验用 15 图测试集验证生产流程（v0.3.4 + patch=64）的质量等价、去卷积有效性、确定性与版本/变量不变性。
> 指标口径：**官方口径**（论文 `4_0_result_evaluate.py`）：每图 P3/P99.5 归一化 → `np.clip(0,2.5)` → skimage PSNR/SSIM `data_range=2.5`。文中所有 PSNR/SSIM 均为此口径。

## 结论

**生产流程（napari-fluoresfm v0.3.4 + patch=64 + 去卷积 prompt + sf_lr=1）在 15 图测试集上近精确复现 bundled 参考，并对 SIM 真值有稳定的大幅改善。**

| 验证维度 | 结果（官方口径） |
| --- | --- |
| 15 图输出 vs bundled 参考 | **PSNR 48.13 dB / SSIM 0.9974**（最低 46.0 dB / 0.997） |
| 15 图输出 vs SIM | **35.15 dB**；相对 WF 输入（27.84 dB）**改善 +7.31 dB**，15 图全部一致 |
| 单 GPU 字节确定性 | 连续 3 次运行 **SHA 全同**（PSNR=∞） |
| flash 开/关 | 输出一致（77 dB），flash 无质量影响 |
| 新旧版本（d623403 vs v0.3.4） | 输出一致（77 dB），质量等价 |

- 平均 **48.13 dB / 0.9974**（官方口径）；最低 **45.99 dB / 0.9968**。全部 ≥46.0 dB / ≥0.997，近精确复现。

## 实验 B：15 图去卷积 vs SIM（官方口径）

每图 P3/P99.5 归一化 → clip[0,2.5] → data_range=2.5（SIM 降采样到 502 对齐输出分辨率）：

- 模型输出平均：**PSNR 35.15 dB**
- WF 输入基线：27.84 dB
- **改善：PSNR +7.31 dB**，15 张全部一致为正。

去卷积有效性在全集上成立（输出显著更接近 SIM 真值，远高于输入）。

## 实验 C：确定性下限

- **单 GPU（cuda:0）、连续、安静运行：3 次逐字节相同**（SHA 全同 `bc53ce...`，PSNR=∞，SSIM=1.0）。run-to-run 波动下限为 **0**。
- **跨 GPU（cuda:0 vs cuda:1）：低阶位差异 ~2⁻⁹**（SHA 不同，质量 77 dB+ 级别）。
- 修正先前结论：管线非「run-to-run 不确定」；单 GPU 完全确定，仅跨 GPU 有设备级低阶位差异。

## 实验 D：变量隔离

| 对比 | PSNR | 结论 |
