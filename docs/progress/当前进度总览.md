# FluoResFM 当前进度总览

> 更新：2026-07-29。本文是状态索引；原始 TIFF、权重、日志和逐图 CSV 均位于 Git 忽略的 `experiments/`，各结论以链接的独立记录为准。

## 当前结论

- 预训练模型、云端 GPU 推理、回传归档、本地隔离式评估和配对统计链路均已跑通。
- 已完成的改进线全部属于 P2：它们检验当前 15 张 BioSR_MT 捆绑图上的提示可靠性与评估行为，**不构成论文复现、泛化提升或模型优越性证据**。
- 独立 BioTISR 外部复验当前被数据转换协议阻塞，而非被模型或算力阻塞。

## 当前停止条件

不再对同一 15 张 BioSR_MT 图继续增加提示扰动。这样只会扩大探索性比较次数，不能解决独立性、协议可追溯性或泛化问题。

要进入独立复验，至少需要以下之一：

1. 作者已转换的 BioTISR 测试集；或
2. 可审计的 RawSIM→WF/GT 流程，包含帧选择/平均、SIM 重建软件与参数、OTF、配准裁剪归一化，以及 ROI/时间点到测试条目的逐文件映射。

若仅自行构造 RawSIM 派生数据，必须新建、冻结并报告为 P2 协议，不能与 FluoResFM 的 P0/P1 或论文数值混合比较。

## 下次恢复工作的顺序

1. 获得上述转换材料后，先运行 `scripts/audit_biotisr_protocol.py`，要求至少一个数据集的 index、input、reference 三者逐文件 100% 配对。
2. 对通过审计的数据集做小型 GPU smoke test；预测回本地后校准评估实现。
3. 仅在独立图像上复验：荧光标记敏感性、DA 与有参考指标冲突、以及提示分歧的风险排序。
4. 在该验证之前，不开展微调或宣称改进泛化性能。
