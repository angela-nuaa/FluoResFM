# FluoResFM 当前进度总览

> 更新：2026-08-08。本文是状态索引；原始 TIFF、权重、日志和逐图 CSV 均位于 Git 忽略的 `experiments/`，各结论以链接的独立记录为准。

## 当前结论

- 预训练模型、云端 GPU 推理、回传归档、本地隔离式评估和配对统计链路均已跑通。
- 已完成的提示敏感性实验（P2 线）检验当前 15 张 BioSR_MT 捆绑图上的提示可靠性与评估行为，**不构成论文复现、泛化提升或模型优越性证据**。
- BioTISR-CCP bundled example 的 `Cell_001` 已完成原始 MRC 端到端复现：60 张 WF 和 20 张 SIM 完整帧严格相等，256 对 SR 补丁在 float32 TIFF 容差内一致。其余细胞与论文完整划分仍未得到逐文件验证。
- BioSR-MT bundled example 已完成原始 MRC 审计：测试、训练全图与实际训练 patch 均可复现；其证据范围同样限于该 bundled example。
- **推理生产已完成（质量等价）**：bundled `_fluoresfm` 参考实际在 **patch=64** 下推理（15 图官方口径 48.13 dB / 0.9974 近精确复现；patch=256 仅 42.00 dB）。生产配置 v1：patch=64、batch=8、compile=false、sf_lr=1、无 flash；判定标准为质量等价（非逐字节）。6 级别单图验证全过（5 级别 80–84 dB，level_3 唯一近精确 47 dB）。
- **批量生产 v1 + SIM 锚定等价**：90 全图 + 735 测试 patch 已生产（质量等价）。90 图 vs SIM：候选 34.68 ≈ 官方参考 34.63 dB（Δ +0.052，逐级 ≤0.18），均较输入 +7.3 dB → **生产真值保真度与官方推理等价**（锚定 SIM、非循环）。
- **确定性再修正（2026-08-08）**：同进程内两次 predict 逐字节一致；**跨进程（同 GPU 同配置全新进程）不确定**（~1e-3，质量 80+ dB）。根因：TF32 CuBLAS 非确定性 reduction + `cudnn.benchmark=True` 跨进程算法选择差异。08-07 的「单 GPU 逐字节确定」（det_run1..3）为当时环境恰好稳定，不具可复现性。
- **可选确定性变体（2026-08-08）**：跨进程逐字节可复现可用 `CUBLAS_WORKSPACE_CONFIG=:4096:8` + `use_deterministic_algorithms` + 运行时注入 benchmark=False 的 predict 实现（磁盘源码不变）。已验证 41.tif 3 进程、level_3 15 图两进程全部逐字节一致；质量与主生产等价。配置 `biosr_mt_fluoresfm_batch_production_deterministic_v1.json`。
- **官方实现对比完成，7 项待确认全部闭环**：论文主协议（完整 8 字段文本 + 每图 P3/P99.5 归一化，无背景扣除）与生产配置对齐；官方代码里的滚动球背景扣除在 bundled 502×502 上不可应用，vs-SIM 保持无 bkg 自洽口径。

## 当前停止条件

不再对同一 15 张 BioSR_MT 图继续增加提示扰动。这样只会扩大探索性比较次数，不能解决独立性、协议可追溯性或泛化问题。

要进入独立复验，至少需要以下之一：

1. 作者已转换的 BioTISR 测试集；或
2. 可审计的 RawSIM→WF/GT 流程，包含帧选择/平均、SIM 重建软件与参数、OTF、配准裁剪归一化，以及 ROI/时间点到测试条目的逐文件映射。

将该流程应用到其余 RawSIM 细胞时，必须逐细胞保留输入哈希、转换配置和审计结果，不能将未对照的文件称为 example 的逐文件复现。

## 下次恢复工作的顺序

推理线：
1. 超分协议（sf_lr=2）如需生产：当前流程与 P2 相当（15 图 26.69 vs 26.47 dB，P2 口径），需另建配置与验证，不在去卷积生产链内。

预处理/复验线：
2. 将已验证的 example 规则应用到后续细胞时，先建立逐文件映射与独立审计清单。
3. 在获得可对照的保留集或作者划分前，不开展基于旧候选流程的零样本比较或微调。
4. 若获得作者转换材料，先运行 `scripts/audit_biotisr_protocol.py`，再将其作为独立的严格复验线路处理。
