## 9. 阶段 3 执行结论（2026-08-07 晚）

### 9.1 根因：插件禁用了 flash attention

- 上游模型（`qiqi-lu/fluoresfm`）`models/unet_attention.py` 默认 `use_flash_attention: bool = True`，官方脚本 `3_0_test_it2i.py` 默认 `patch_size=256`。
- napari 插件两份拷贝（`2fded7c`、`d623403`）均改为 `use_flash_attention: bool = False`。
- 模型 `attention_levels=[0,1,2,3]` 在全分辨率做二次方注意力：patch=256 时注意力矩阵需 **256 GiB**（fp16），无 flash 必然 OOM。

### 9.2 实验证据

| 配置 | 能否运行 | vs bundled 参考（15 图均值，官方口径） |
| --- | --- | --- |
| patch=256、无 flash（计划参数） | OOM 256 GiB | — |
| **patch=256、flash=True**（flash-attn 2.7.0.post2） | 能 | 42.00 dB / SSIM 0.9915（质量等价） |
| **patch=64（flash 开/关均可）** | 能 | **48.13 dB / SSIM 0.9974（近精确复现）** |

- **关键发现**：bundled 参考实际在 **patch=64** 下推理（官方口径 48.13 dB 近精确复现 ≫ patch=256 的 42.00 dB）；patch=64 无需 flash（注意力矩阵小）。
- **确定性**：单 GPU、连续、安静运行时**逐字节确定**（3 次运行 SHA 全同）；跨 GPU 存在设备级低阶位差异（~2⁻⁹）。先前「非字节确定」表述为并发双 GPU 干扰所致，已修正。
- 补充实验（15 图）：去卷积对 SIM 相对输入改善 **+7.31 dB**（官方口径）；flash 无质量损失；新旧版本（d623403 vs v0.3.4）质量等价（互比 77 dB）。详见 `docs/experiment_results/推理实验-01_...md`。

### 9.3 已定生产配置（v1）

- **版本**：napari-fluoresfm **v0.3.4（`2fded7c`）**（云端源码已还原为干净 v0.3.4，git 无修改）。
- **推理参数**：**patch=64**、overlap=16（patch//4，自动）、batch=8、compile=false、sf_lr=1、去卷积 prompt、AMP（predict 固定 True）。
- **flash**：**不需要**（patch=64 注意力矩阵小）；flash-attn 2.7.0.post2 曾构建验证，后已卸载清理（如需 patch=256 大图可重建）。
- **环境**：云端 `.venv`（Python 3.10.12、torch 2.6.0+cu124）。
- **判定标准**：质量等价（PSNR/SSIM vs bundled 参考，**官方口径**基线 48.13 dB / 0.9974）。生产配置文件：`configs/biosr_mt_fluoresfm_production_v1.json`。
- **已验证**：15 图（41–55）patch=64 输出 vs 参考（官方口径）PSNR=48.13 dB（最低 45.99）、SSIM=0.9974（最低 0.9968）。
