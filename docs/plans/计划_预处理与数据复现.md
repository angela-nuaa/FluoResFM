## 当前边界

- 两项预处理实验均为 bundled example 的内容级证据，不等价于论文完整训练/测试划分。
- BioTISR 外部 SR 工作簿仍缺逐文件索引、细胞/时间点映射与完整测试划分；因此不得据此报告 P0/P1 性能复现。
- 不使用、也不恢复旧 CCP P2 候选数据、零样本结果或微调结果。

## 后续恢复顺序

1. 若将预处理实验-02 的规则用于其他 CCP 细胞，先建立逐文件输入哈希、转换配置与独立审计；此阶段不进行推理。
2. 若获得作者转换测试材料，先执行 `scripts/audit_biotisr_protocol.py` 验证逐文件输入、参考图和元数据映射。
3. 只有数据协议通过后，才另行规划提示词、零样本推理、评测或微调。

## BioSR-MT 全目录严格生产（阶段 1–2）

本阶段只生产已经由预处理实验-01验证的内容，且一律写入新的 `data/derived/` 运行目录：

1. 冻结 `example/data/BioSR_MT` 的完整文件、内容哈希、dtype 与数组哈希清单；其中包括尚未有严格生成协议的 `_fluoresfm` 测试派生文件与测试 patch。
2. 从公开原始 MRC 严格生产测试/训练 WF、SIM、实际训练索引的两种 patch 网格和全部索引文本，并逐文件对比 bundled example。

执行入口为 `configs/biosr_mt_verified_materialization_20260805_r3.json` 与 `scripts/materialize_biosr_mt_verified_assets.py`。该阶段不覆盖 `example/`，也不将 `_fluoresfm` 测试派生图或其测试 patch 误列为已严格复现；它们须在后续独立审计中获得确切变换链。

## 不可变规范

- 每次运行使用新目录，保留配置、命令、版本、随机种子和输入 SHA-256。
- 原始数据、派生数据、预测与评测结果均位于 Git 忽略目录；Git 只保存脚本、配置和中文审计记录。
- 论文协议复现、近似复现与探索性实验必须分开编号、目录和结论。
