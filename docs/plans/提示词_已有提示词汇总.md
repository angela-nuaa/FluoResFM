# FluoResFM 提示词汇总（多来源收集）

> 目的：为「新数据集如何写提示词」提供依据。汇总自 bundle、上游仓库、P2 实验、论文文献的现有提示词。
> 配套规范：基于本汇总的编写指南见 [`协议_提示词编写.md`](../protocol/协议_提示词编写.md)。

## 1. 规范模板（8 字段）

几乎所有完整提示词遵循同一 8 字段结构（`;` 分隔，句号结尾）：

```
Task: <任务>; sample: <样本>; structure: <结构>; fluorescence indicator: <荧光团>(<通用名>);
input microscope: <输入显微类型> with excitation numerical aperture (NA) of <激NA>, detection numerical aperture (NA) of <探NA>;
input pixel size: <宽> x <高> nm; [超分时接 "Nearest interpolation with a factor of N"]
target microscope: <目标显微类型> with excitation numerical aperture (NA) of <激NA>, detection numerical aperture (NA) of <探NA>;
target pixel size: <宽> x <高> nm.
```

## 4. P2 实验条件提示词（敏感性证据）

### P2-1 语义等价改写（相对规范提示词）

| 条件 | 改动 | PSNR 变化 |
| --- | --- | --- |
| 01_full | 无（bundle 原文） | 0（26.466） |
| 任务改写 | "Task: 2× super-resolution from wide-field to SIM" | −0.70 dB |
| 结构改写 | "microtubules (MT cytoskeleton)" | −0.20 dB |
| 成像改写 | 显微镜/像素尺寸换措辞（"illumination: wide-field (ex NA…)"） | **−0.97 dB** |
| 全提示改写 | 以上全改 | **−2.90 dB** |

### P2-2 成像冲突阶梯（目标元数据写错）

`01_全对` / `02_wrong_target_modality` / `03_wrong_target_pixel_size` / `04_both_wrong` —— 目标模态/像素尺寸写错 → 质量下降。

### P2-3 单字段条件冲突

`01_全对` / `02_wrong_input_modality` / `03_wrong_structure` / `04_wrong_fluorescence_indicator` —— 输入模态/结构/荧光团写错 → 有损。

## 5. 论文（Nature Communications 2026）

文本先验 = **三类信息拼接**：
- 任务类型：denoising / deconvolution / super-resolution
- 结构类型：CCP、ER、F-actin、MT、nucleus、mitochondria 等（20+ 结构）
- 成像条件：显微类型（宽场/共聚焦/STED/SIM…）+ 参数 + 荧光指示剂
- **输入与目标图像的元数据都包含**

## 6. 关键规律（供新数据集参考）

1. **任务 + 成像条件字段最敏感**（改写 −0.97~−2.9 dB），结构字段其次（−0.2 dB）。
2. **规范措辞 > 自由措辞**：用 bundle/上游原文措辞与词汇表，避免改写。
3. **物理参数必须真实**：目标模态/像素尺寸/结构/荧光团写错均有损。
4. **字段可裁剪**：部分任务只用部分字段（上游 5 套模板），但完整 8 字段最稳。
5. **NA 措辞有历史不一致**（"of 1.35, detection numerical aperture (NA) of 1.3" vs "of 1.41."带尾随点），新数据建议用规范写法。
