# FluoResFM 提示词编写规范

> 版本：v1（2026-08-07）。依据：`提示词_已有提示词汇总.md`（bundle/上游/P2/论文多来源）；生产验证（`阶段3-01/02`）。
> 适用范围：为新数据集编写 FluoResFM 推理/生产提示词。

## 1. 原则

1. **提示词是成像物理描述**：逐字段描述「输入是什么、目标是什么」的真实采集元数据，不是自由文本。
2. **规范措辞优先**：使用 bundle/上游原文措辞与词汇表，避免语义等价改写（P2 实测：全提示改写 −2.9 dB）。
3. **字段必须真实**：任务、结构、显微类型、NA、像素尺寸、荧光团写错均有损（P2-2/P2-3）。
4. **任务与成像条件字段最敏感**（−0.97~−2.9 dB），结构字段其次（−0.2 dB），需最小心。
5. **完整 8 字段最稳**：可裁剪但不要随意缺字段。

## 2. 规范模板（8 字段，唯一推荐形态）

```
Task: {任务}; sample: {样本}; structure: {结构}; fluorescence indicator: {荧光团}({通用名}); input microscope: {输入显微类型} with excitation numerical aperture (NA) of {激NA}, detection numerical aperture (NA) of {探NA}; input pixel size: {宽} x {高} nm; {插值说明}; target microscope: {目标显微类型} with excitation numerical aperture (NA) of {激NA}, detection numerical aperture (NA) of {探NA}; target pixel size: {宽} x {高} nm.
```

- 字段用 `; ` 分隔，句号结尾；`input pixel size` 与 `target microscope` 之间为超分任务插入「插值说明」。
- 已验证示例（bundle 原文）：

```
# 去卷积（同尺寸）
Task: deconvolution; sample: fixed COS-7 cell line; structure: microtubule; fluorescence indicator: mEmerald (GFP); input microscope: wide-field microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; input pixel size: 62.6 x 62.6 nm; target microscope: linear structured illumination microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; target pixel size: 62.6 x 62.6 nm.

# 超分辨率 ×2（含插值说明）
Task: super-resolution with a scale factor of 2; sample: fixed COS-7 cell line; structure: microtubule; fluorescence indicator: mEmerald (GFP); input microscope: wide-field microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; input pixel size: 62.6 x 62.6 nm. Nearest interpolation with a factor of 2; target microscope: linear structured illumination microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; target pixel size: 31.3 x 31.3 nm.

# 去噪（输入=目标显微）
Task: denoising; sample: fixed COS-7 cell line; structure: microtubule; fluorescence indicator: mEmerald (GFP); input microscope: wide-field microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; input pixel size: 62.6 x 62.6 nm; target microscope: wide-field microscope with excitation numerical aperture (NA) of 1.35, detection numerical aperture (NA) of 1.3; target pixel size: 62.6 x 62.6 nm.
```

## 3. 逐字段规范

| 字段 | 填什么 | 取值来源 | 规则 |
| --- | --- | --- | --- |
| **Task** | 任务类型 | 输入→目标映射 | 同尺寸=去卷积/去噪；放大=`super-resolution with a scale factor of N`；**最敏感字段** |
| **sample** | 样本 | 数据集说明 | `fixed/live` + 细胞系/组织/胚胎（如 `fixed COS-7 cell line`、`live SUM-159 cell`、`D. melanogaster embryo`） |
| **structure** | 成像结构 | 标签/实验 | 用 bundle 词汇（microtubule、clathrin-coated pits、histone、actin、ER…）；避免自由改写 |
| **fluorescence indicator** | 荧光团 | 实验方案 | `{名称} ({通用名})`，如 `mEmerald (GFP)`、`mRFP1 (RFP)` |
| **input microscope** | 输入显微类型+NA | 采集元数据 | 类型用词汇表枚举；`with excitation numerical aperture (NA) of {激}, detection numerical aperture (NA) of {探}` |
| **input pixel size** | 采集像素尺寸 | 元数据 | `{宽} x {高} nm` |
| **插值说明**（仅超分） | 输入上采样方式 | 预处理流程 | `Nearest interpolation with a factor of N.` |
| **target microscope** | 目标/真值显微类型+NA | 参考图采集 | 同 input 写法；**写错有损**（P2-2） |
| **target pixel size** | 目标像素尺寸 | 参考元数据 | `{宽} x {高} nm`；**写错有损**（P2-2） |

## 4. 任务类型模板速查

| 任务 | Task 措辞 | 像素关系 | 插值说明 | target microscope |
| --- | --- | --- | --- | --- |
| 去卷积 | `deconvolution` | 输入=目标尺寸 | 无 | 与输入可同可异（如 WF→SIM 同尺寸） |
| 去噪 | `denoising` | 输入=目标尺寸 | 无 | 与输入相同 |
| 超分辨率 | `super-resolution with a scale factor of {N}` | 目标=输入×N | `Nearest interpolation with a factor of {N}.` | 与输入不同（更高分辨显微） |
| 其他（投影等） | 按输入→目标语义 | — | 按需 | — |

## 5. 词汇表（取自 constants.py 与 bundle）

**显微类型**（`task_struc_micro_voc`）：wide-field microscope、spinning disc confocal microscope、multiphoton laser-scanning microscope、light-sheet microscope、two-photon laser-scanning microscope、confocal microscope、linear structured illumination microscope、non-linear structured illumination microscope、stimulated emission depletion microscope 等。

**结构类型**（bundle + 论文）：microtubule、clathrin-coated pits、histone、actin/F-actin、ER、nucleus、mitochondria、CCP 等。

## 6. 常见错误与避坑

1. **NA 措辞不统一**：历史有 `...of 1.35, detection numerical aperture (NA) of 1.3`（规范）与 `...of 1.41.`（带尾随点、缺 detection）。新数据一律用规范写法（含 detection NA，无尾随点）。
2. **拼写错误**：上游有 `struture` 变体；勿沿用。
3. **目标元数据写错**（模态/像素/结构/荧光团）→ 质量下降（P2-2/P2-3），新数据集必须核对参考图真实来源。
4. **自由改写/翻译** → 掉分（P2-1），只用规范措辞。
5. **未知参数**：填最合理估计并标注不确定，不能留空字段。
6. **多任务混用**：每个任务一条提示词，勿把超分与去卷积混在一个 Task 里。

## 7. 新数据集编写流程

1. **确定任务映射**：输入→目标（同尺寸/放大倍率）→ 定 Task 与插值说明。
2. **提取采集元数据**：从原始数据头（MRC/metadata 表）、数据集说明、论文采集参数提取样本/结构/荧光团/显微类型/NA/像素尺寸；**不臆造**。
3. **套用 8 字段模板**：只改数值，保持措辞原样。
4. **核对目标字段**：目标显微类型/像素尺寸必须与参考图（真值）一致。
5. **用词汇表校验**：显微类型与结构用枚举表述。
6. **验证**（推荐）：按 `阶段3-02` 方法在 1–2 张图上跑，对比质量指标是否在合理范围（vs 参考 ≥37 dB 量级）；若异常优先检查 Task 与成像字段。

## 8. 验证基线

- 生产配置：`configs/biosr_mt_fluoresfm_production_v1.json`（patch=64、无 flash、去卷积 prompt）。
- 质量基线：15 图 vs bundled 参考 PSNR 48.13 dB / SSIM 0.9974（官方口径，见 `阶段3-02`）。
- 敏感度参考：任务改写 −0.7 dB、成像改写 −0.97 dB、全改 −2.9 dB（P2-1）。
