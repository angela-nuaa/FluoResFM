# FluoResFM 改进实验计划

> 状态：历史设计与停止规则（2026-07-28）；当前完成状态见[当前进度总览](../progress/当前进度总览.md)。
> 证据等级：所有本计划中的实验在获得经核验的保留集前均为 P2 补充实验。
> 目标：检验文本条件的可靠性、错误元数据的风险、条件融合的可诊断性及评估结论的稳健性；不以当前小规模结果宣称泛化提升。

本文件与[补充实验与复现计划](复现实验计划.md)分工：后者处理下载、协议核验与论文复现；本文件仅维护独立的改进假设、最小原型与判定规则。

## 不可变约束

- 不修改 `repos/fluoresfm/` 或其他上游基线代码；新增实现只放在 `scripts/` 和本文件引用的独立配置中。
- GPU 仅生成预测或执行训练；指标、统计、可视化与汇总固定在本地完成。
- 原始数据、权重、TIFF 预测、日志和实验产物写入 Git 忽略目录；每次运行新建目录并保存 `manifest.json` 与 `run.md`。
- 对照组、固定变量、排除规则和主要指标必须在运行前写入 manifest；不得根据结果再选择有利指标。
- 基线下载、逐文件元数据及独立保留集未完成前，优先运行诊断实验和最小原型；结论限于所测试的图像、提示族与权重版本。

## P2-1：语义等价改写鲁棒性（首要实验）

**动机。** 字段删除和明显错误提示已显示输出会变化，但不能区分模型响应的是字段语义、固定措辞，还是模板位置。

**可检验假设。** 在任务、结构和成像物理含义均保持不变时，等价改写相对规范提示的保真度下降与输出差异应小于已观察到的字段删除效应。

| 项目 | 预注册内容 |
| --- | --- |
| 数据范围 | 当前 BioSR_MT 的 15 张捆绑测试图；仅作 P2 提示敏感性诊断。 |
| 对照 | `01_full`：当前规范完整提示。 |
| 条件 | 任务字段等价改写、结构字段等价改写、成像字段等价改写、全提示改写；每个条件只改一个预定义文本片段，最后一项除外。 |
| 固定变量 | 权重、图像、图像预处理、尺度、设备、推理参数、随机种子、文件配对和本地评估版本。 |
| 主要指标 | 按图配对的 PSNR、MS-SSIM、ZNCC、RSP、NRMSE、RSE；输出相对 `01_full` 的像素差异作为辅助诊断。 |
| 决策规则 | 完整报告各条件的均值、逐图差异、置信区间或预先指定的配对检验及多重比较校正；不以单一 DA/SSIM 改善判定成功。 |
| 预期失败模式 | 改写无意中改变物理含义或数值；BiomedCLIP 对原模板敏感；15 张样本的估计不稳定。 |

**最小原型。** 新建独立脚本 `scripts/run_mt_semantic_paraphrase.py`，复用规范提示的输入索引与推理约定，但不修改现有消融脚本。条件文本、变更字段与语义核查说明写入 manifest。先用 2 张图进行 GPU smoke test；图像数、文件名和 manifest 通过核验后，才运行全部 15 张；随后在本地调用既有评估与配对汇总脚本。

```bash
# 将 FILE_A、FILE_B 替换为 BioSR_MT/test.txt 中的两个文件名；GPU 仅用于此步的预测。
python scripts/run_mt_semantic_paraphrase.py --device cuda:0 \
  --runs-dir experiments/semantic_paraphrase/20260728_mt_smoke2 \
  --images FILE_A FILE_B

# 对 smoke-test 输出在本地评估；通过后才以新 runs-dir 执行 15 张全量推理。
python scripts/evaluate_ablation_isolated.py --dataset BioSR_MT \
  --runs-dir experiments/semantic_paraphrase/20260728_mt_smoke2 --workers 2
```

**解释边界。** 若改写稳健，只能说明该提示族内的表述变化未显著影响当前样本；若不稳健，也不能单独证明模型不理解语义，替代解释包括文本编码器分词、模板分布偏移及改写质量。

## P2-2：元数据冲突强度曲线

**动机。** 当前仅测得一种目标模态替换，其影响小于字段删除；需要判断是冲突强度不足，还是该字段影响确实有限。

**可检验假设。** 在预定义的、物理上可解释的冲突层级中，冲突范围或强度增加会伴随相对完整提示更大的输出分歧和有参考保真度损失。

| 项目 | 预注册内容 |
| --- | --- |
| 对照 | 规范完整提示；P2-1 中语义等价提示可作为措辞稳健性参照。 |
| 条件 | 单一成像字段冲突、多个成像字段一致冲突、任务冲突；每组分别报告，不合并成单一分数。 |
| 固定变量 | 与 P2-1 相同；每次只引入一个预定义冲突层级。 |
| 指标 | P2-1 的有参考指标、相对完整提示的输出差异、失败/异常输出比例。 |
| 预期失败模式 | 图像输入主导而文本效应微弱；人工组合在现实中不可能；不同冲突类别不可比较。 |

**解释边界。** 这是错误先验风险诊断，不是对真实未知实验条件的性能测量。

## P2-3：条件融合/敏感性扫描原型

**动机。** 当元数据不可靠时，需要先知道输出对条件变化的敏感程度，再考虑任何推理端策略。

**可检验假设。** 完整条件与弱条件（字段删除或冲突）之间的输出轨迹可作为样本级不确定性诊断；高敏感样本应更常出现有参考保真度变化。

| 项目 | 预注册内容 |
| --- | --- |
| 原型范围 | 只包装现有推理接口，输出完整条件、弱条件及预定义扫描点；不改动上游网络或权重。 |
| 对照 | 完整提示、删除字段提示、错误字段提示。 |
| 固定变量 | 输入、权重、尺度、采样设置和评估流程。 |
| 指标 | 有参考保真度、扫描点间输出差异、每图敏感性排名；无参考时仅报告分歧，不解释为质量。 |
| 预期失败模式 | 输出混合不具物理意义；平滑造成表面指标改善；敏感性不等于不确定性。 |

**进入条件。** 仅在 P2-2 明确至少一种可解释冲突类别、且独立脚本能完整记录条件后实施。

## P2-4：评估可靠性与形态一致性

**动机。** CCP 提示删除中 SSIM/MS-SSIM 与其他有参考指标的排序已不一致，单一指标可能偏好平滑输出。

**可检验假设。** 指标排序冲突会集中于可识别的形态或频率变化；多指标共同报告可减少单指标误判。

| 项目 | 预注册内容 |
| --- | --- |
| 数据 | 已有 MT 和 CCP 预测；无需 GPU 推理。 |
| 对照 | 每个条件与其相同图像的完整提示输出配对。 |
| 方法 | 本地计算指标相关性、逐图排序一致性、边缘/频谱诊断；只有存在可信标注时才加入 MT 纤维长度、CCP 尺寸或下游分割指标。 |
| 主要输出 | 指标冲突图、逐图异常清单、预先定义的多指标报告模板。 |
| 预期失败模式 | 形态代理指标本身未验证；无独立标注时无法证明恢复结构真实。 |

## 通用验收与停止规则

- 运行前：确认新目录不存在；输入、参考图、元数据和条件文本均有清单及哈希。
- 运行后：确认每条件图像数和文件名集合一致；本地评估不静默跳过错误；Git 状态不包含数据、权重、TIFF 或实验产物。
- 停止扩展：若 smoke test 揭示提示解析、文件配对或尺度不一致，先修复记录/脚本并重新 smoke test，不进入全量推理。
- 升级条件：只有在独立、经逐文件元数据核验的保留集上重复，并通过评估校准后，才讨论 P1 级近似复现；P2 结果永不单独支持泛化或方法优越性主张。
